# Interactive Wildlife Species Map

An interactive web map built with Python, GeoPandas and Folium that visualises wildlife species distributions using shapefiles.

## Features

- Interactive map
- Multiple species layers
- Route-based colouring
- Hover tooltips
- Layer control

## Technologies

- Python
- GeoPandas
- Folium
- Jupyter Notebook

## Future Improvements

- Species search
- Filtering
- Database integration
- Web application deployment

The data files were sourced here: https://www.bto.org/our-work/science/research-areas/wetland-and-marine/soss/migration-zone-shapefiles
